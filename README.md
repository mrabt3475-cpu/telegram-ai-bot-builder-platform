# Telegram AI Bot Builder Platform

منصة إنشاء بوتات تيليغرام بالذكاء الاصطناعي - AI-powered Telegram bot builder platform

## الوظائف الرئيسية

- ✅ إنشاء بوتات تيليغرام تلقائياً باستخدام AI Agent
- ✅ نظام أرصدة (Credits System) لتتبع الاستخدام
- ✅ تجربة مجانية للمستخدمين الجدد
- ✅ نظام الإحالة والعمولات
- ✅ محفظة إلكترونية داخلية
- ✅ تسجيل الدخول عبر تيليغرام
- ✅ واجهة ويب احترافية وسهلة الاستخدام

## التقنيات المستخدمة

- Node.js
- Express.js
- Telegram Bot API
- OpenAI API
- MongoDB
- JWT Authentication
- React.js
- Tailwind CSS

## التثبيت

```bash
npm install
```

## التشغيل

```bash
npm start
```

# Frontend - Telegram AI Bot Builder

## Tech Stack
- React.js
- Tailwind CSS
- Axios
- React Router
- JWT Authentication

## Installation

```bash
cd frontend
npm install
```

## Running

```bash
npm start
```

## Features

- User authentication via Telegram Login Widget
- Dashboard to manage bots
- Create new bots with AI assistance
- View bot statistics
- Referral system
- Credits management
